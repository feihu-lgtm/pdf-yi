# PDF译 v60

打开 PDF → 后台翻译 → 自动生成「左边原版、右边译文」的双栏 PDF。
- 本地打开的 PDF：双栏 PDF 自动存在原文件旁边，叫「原文件名_双栏.pdf」。
- 在 Zotero 里右键翻译的：双栏 PDF 自动挂回同一个条目。原附件存在 Zotero 里，就复制进 Zotero；原附件是链接到外部的文件，就存在原文件旁边、以链接挂上。
- 你在阅读器里做的高亮和批注，写成真正的 PDF 批注，放在左边原文上。

两种用法，同一份页面代码：

| | 轻量版 | Mac 程序 |
|---|---|---|
| 打开 | 双击 `启动PDF译.command`，在浏览器里 | 双击 `PDF译.app`，独立窗口 |
| 编译 | 不用 | 要，在 Mac 上用 Tauri 编译一次 |
| 后台翻译、菜单栏 | 没有 | 有：关窗口不退出；菜单栏的小鱼按状态换表情，旁边显示「31/60」，可以暂停 |
| 双栏 PDF 存到哪 | 浏览器下载 | 原文件旁边（自动），手动导出弹「存储为」 |
| Zotero 右键翻译 | 不支持 | 支持（要装 `PDF译-zotero.xpi`） |

都要先开着本机的 Magpie 反代（`http://127.0.0.1:3426/v1`）。

## 〇、架构（v53 起是双架构）

| 部分 | 文件 | 做什么 |
|---|---|---|
| 全量版（读书用） | `www/index.html` | 阅读、高亮批注、纯文本/三栏、AI 对话、导出……所有功能 |
| 后台引擎（翻译用） | `www/worker.html` + `www/worker.js` | Mac 程序里看不见的窗口：Zotero 交来的书、菜单栏「后台翻译文件…」。不画页面，只做 提取 → 翻译 → 生成双栏 PDF → 存盘或挂回 Zotero，并驱动菜单栏 |
| 核心模块 | `www/core/textutil.js` `store.js` `extract.js` `translate.js` `bilingual.js` | 后台引擎用的提取、缓存、翻译、双栏 PDF；从全量版原样移植（`tools/assemble-core.py` 生成），结果与全量版逐段一致 |

- 两边共用同一份缓存（IndexedDB `PDFTransCache`）和设置：后台翻过的书，用全量版打开直接有译文。
- 后台任务一律由 Rust 接收（v54.1）：Zotero 链接和「后台翻译文件…」的对话框都在 Rust 里处理，放进待办列表，后台引擎来取（启动时也取一次，不会丢）。
- 后台引擎窗口不被暂停（v54.2，小宝实测找到的根因）：WebKit 默认会暂停看不见的窗口里的网页，后台引擎因此卡在半路；worker 窗口设了 `"backgroundThrottling": "disabled"`。这个选项要 macOS 14 及以上，13 及以下没验收。
- 后台引擎不依赖计时器（v54）：macOS 会冻结看不见的窗口里的计时器。菜单栏「后台引擎状态」可以打开它的窗口看任务和日志。
- 双栏 PDF 一次复制整本原页、共用字体和图片（v54）：大小和原文件差不多；没旋转的页保留原 PDF 自带的链接和批注。
- 后台引擎一共约 640 行；全量版约 3800 行，下一步会改成也调用 core/ 里的模块。

## 一、轻量版

1. 双击 `启动PDF译.command`。第一次如果提示“无法验证开发者”：右键 → 打开 → 打开。
2. 浏览器打开 `http://127.0.0.1:3427/index.html`。
3. 用完双击 `关掉PDF译.command`。

需要系统自带的 `python3`（装过 Xcode 命令行工具就有）。

## 二、Mac 程序（小宝编译）

**准备环境（第一次）**

```bash
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
cargo install tauri-cli --version "^2" --locked
```

**编译**

```bash
cd PDF译/mac-app/src-tauri
cargo tauri build
```

产物：`mac-app/src-tauri/target/release/bundle/macos/PDF译.app`。把它拖进「应用程序」。
程序没有签名，第一次打开要右键 → 打开，或者 `xattr -cr "/Applications/PDF译.app"`。

**一定要先打开一次 PDF译.app**，macOS 才会记住 `pdfyi://` 链接由它来打开，Zotero 插件才叫得起它。

调试：`cargo tauri dev`。

## 三、Zotero 插件

1. Zotero 7：工具 → 插件 → 右上角齿轮 → 从文件安装插件… → 选 `PDF译-zotero.xpi`。
2. 在条目或 PDF 附件上右键 → 「用 PDF译 翻译（左原文右译文）」。可以一次选好几个条目。
3. PDF译 被叫起来，在后台一本接一本地翻，不弹「先翻哪里」，等清理规则定好就全部按顺序翻。
4. 翻完，条目下面多一个「原附件名_双栏」的 PDF。同一条目再翻一次，旧的那份会被移到回收站、换成新的。

要求：Zotero 开着；Zotero 的本地服务（127.0.0.1:23119）是默认开的，浏览器插件也用它。

## 二之十四、v60：提取阶段的阅读顺序和分段

- 阅读顺序按空白切块（XY-cut）：最宽的空白带先切，竖向空白 ≥8pt（只剩一行时 ≥15pt）且两边有字时优先竖切；块内按行从左到右。首页这种“左边关键词、右边摘要”同一基线的版面会各自分区读取，不再拼成一段。
- 双栏页被阅读顺序拆开的页眉页脚仍按实际最高、最低基线识别并自动清理，不会把右栏页眉插入正文。
- 模型合并后按原文空行、首行缩进、短末行、行距变化细分；请求失败时也走同一套版面分段，失败原因显示在后台面板日志里。
- 真实数据回放脚本在 `tools/tests/`：`real-replay.py` 用真实 PDF 与真实译文回放，`real-refine.py` 查看整页被合并后如何细分。

## 二之十三、v59：后台面板挂在菜单栏小鱼下面
- 左键点菜单栏的小鱼，下面弹出后台面板；点别处收起（面板藏起来照样在翻）。右键点小鱼还是原来的菜单。
- “现在”：正在翻的书，每一页一个小方格（翻好、正在翻、有失败、读不出字一眼看清），页数和还要多久；“添加 PDF”“打开阅读器”；排队的书；最近翻好的书（打开、在访达中显示）。
- “日志”：时间线，翻译和合并只写一句摘要（“翻好 12 段，共 504 字”），点开看模型原文；可以只看出错的、只看引擎的；一键复制给小宝或 Claude。
- “菜单栏”：自己选上下两行各显示什么（百分比、页数、还要多久、失败的页、排队的书、不显示），要不要小鱼的脸和状态符号，有失败时要不要提醒；浅色和深色菜单栏的实时预览。
- 跟着系统的浅色、深色模式。


## 二之十二、v58：每段的框照搬原文；修串页

- 修复（小宝定位）：按栏拆开的两张共用了同一个内容列表数组，译文互相串、原文被盖。现在每张的内容列表和批注列表都单独拆开（原始内容流仍共用）。
- 每段的框照搬原文的左右范围和高度，右半边同位置同大小；不再先判断整页是不是两栏，上半通栏、下半两栏的首页也能镜像。
- 字号从每段原文自己的字号起步，整页统一缩放比例；放不下的段落单独再缩（最小 6pt）。

## 二之十一、v57：每段钉在自己的框里（学 zotero-pdf2zh 的对齐原理）

- 每段译文只能用“它原文第一行的位置到下一段原文的位置”这块地方，放不下就只缩这一段的字号（最小 6.5pt），谁也推不动谁，一段对一段；同一栏里后一段不会叠在前一段上。
- 双栏但没按栏拆开的整页：右半边也分两栏镜像排，横跨两栏的标题、摘要、图注横跨整个右半边。
- 代价：同一页各段字号可能不同（原文密的段，译文字小一些）。真放不下的才进续页（测试里只剩几十字的零头）。

## 二之十、v56：自动术语表

- 开始翻译前，从前 5 页正文（最多 6000 字符）请模型挑出最多 40 条会反复出现的术语和人名、地名、机构名，给出中文学界通用译法；存进这本书的缓存，下次不再提取。
- 每批翻译只附上这一批里实际出现的术语（最多 25 条），全书同一个词同一个译法。提取结果在日志里（类型“术语表”）。设置“自动术语表”可关。全量版和后台引擎都用。

## 二之九、v55：双栏论文按栏对照

- 两栏排版、中间没有通栏内容的页，拆成两张：左栏一张、右栏一张，每张是“这一栏原文 + 这一栏译文”；每一栏按文字实际所在范围切，译文区是这一栏的 1.35 倍宽、行距 1.38 倍。
- 好处：每张约是原页的 1.2 倍宽，按宽度看时比整页双倍宽的排法大得多；每一栏的译文紧挨着原文。
- 有通栏内容的页（第一页标题和摘要、横跨两栏的图注）、旋转页、单栏页仍按整页排。设置里“双栏论文按栏对照”可以关。
- 原页仍是整本一次复制、资源共用；原 PDF 的批注和你的高亮只保留落在这一栏里的。

## 三之〇、v52：状态符号单独放大

- 画里的 Zz、气泡、灯泡从图上抠出来，和暂停的两条竖杠一起放大到接近文字的高度，排在两行字前面；小人的脸只用来认出这是 PDF译。
- 空闲“脸 + Zz”；翻译中“脸 + 气泡 + 40% / 约 6 分”；暂停“脸 + 竖杠 + 暂停 / 40%”；生成和完成“脸 + 灯泡 + 生成 / PDF”“完成 / ✓”。
- 图在 www/vendor/tray/（face-*.png 是脸，sym-*.png 是符号）。

## 三之一、v51：菜单栏“小鱼 + 两行小字”

- 翻译中：上“40%”（有排队“40% +1”），下“约 6 分”或“12/30”；有失败下一行“⚠2 页”。暂停：“暂停 / 40%”。生成：“生成 / PDF”。完成：“完成 / ✓”。空闲只有小鱼。
- 页面把图标和两行字画成一张模板图交给菜单栏（macOS 自带的文字只能一行）；图标去掉留白，撑满菜单栏高度。

## 三之二、v49：页面绘制按需进行（小宝实测的热点）

- 小宝实测：翻译时 WebKit 页面进程峰值 162.7%，Magpie、3426 反代、SSH 隧道几乎是 0。
- PDF 页面只画眼前前后一屏半的那几页，离开五屏以外就释放画布；窗口藏起来时停画。30 页的书打开时只画 2 页（v48 是 30 页全画）。
- API 日志只在设置面板打开时生成。

## 四、v48：减轻发热

- 翻译按字数分批：每次最多约 3000 个英文字符（最多 24 段），一般一页一次；请求次数大约减半，一页的段落放在一起翻，前后文更连贯。
- 输出被截断或有段没对上时，把没翻好的几段对半拆开重翻，最多拆三层，不留半截译文。
- 并发：v50 起按小狐的决定改回默认 6，可选 6 / 8 / 10 / 12 / 16 / 20 / 24 / 30（v48、v49 存下的 2、3、4 自动变成 6）。
- 发给模型的请求之间至少隔 200 毫秒，不会一瞬间全打出去。

## 四之二、v46 新增

- **逐页进度**（小宝的补丁）：顶栏「逐页进度」按钮，列出每一页的状态和段落数，点一页跳过去；译文栏每页标签上有状态徽章。
- **双栏 PDF 的旋转页和裁剪盒**（小宝的补丁）：0°、90°、180°、270° 加裁剪盒，左半边和原页逐像素一致。
- **切换文件时丢弃旧回调**（小宝的补丁）。
- **菜单栏**（v47 换成小狐画的四张小鱼）：空闲是「睡着了」，翻译中是「在思考」，暂停是「平时」，生成双栏 PDF 和完成是「来灵感」；原图在 design/menubar-icons/。旁边的字：翻译中「31/60」，有失败「⚠2」，排队「+1」，暂停「暂停 31/60」，生成双栏 PDF「生成中」，完成「完成」。点开：书名、进度和还要多久、失败的页（点了打开逐页进度）、排队的书、暂停 / 继续、打开上一份双栏 PDF、在访达中显示、显示窗口、翻完通知我、退出。
- **暂停**：不再发新请求，路上的照样翻完；继续以后接着翻。
- **完成通知**：存好或挂回 Zotero 以后弹系统通知，可以在菜单里关掉。

## 五、请小宝重点测的

1. **反代跨域**：要允许 `http://127.0.0.1:3427`（轻量版）和 `tauri://localhost`（Mac 程序）两个来源。
2. **编译**：`cargo tauri build` 能不能过。报错把原文贴过来。
3. **后台翻译**：开一本 100 页以上的书，翻到一半关窗口，十分钟里看菜单栏的数字有没有一直在走。已经在 Info.plist 里关掉了 App Nap，但网页视图藏起来以后会不会被 WebKit 自己降速，要实测。
4. **Zotero**：
   - 存在 Zotero 里的附件：右键翻译，翻完条目下面多一份「…_双栏」，能打开。
   - 链接到外部的附件：翻完原文件旁边出现「…_双栏.pdf」，条目下面多一个链接附件。
   - 同时选三个条目右键：三本一本接一本翻完，都挂上。
5. **本地打开**：用「打开文件」按钮或者把 PDF 拖进窗口，翻完原文件旁边出现「…_双栏.pdf」。
6. **菜单栏**（v47）：四种表情在浅色和深色菜单栏里都看得清，跟着状态换；翻译时数字在走；点「暂停翻译」后不再发新请求，「继续翻译」后接着翻；翻完有系统通知；「在访达中显示」能定位到双栏 PDF。
7. **逐页进度**（v46）：面板里的状态和实际一致；点页号能跳过去。
8. **译文字号**：设置里「双栏 PDF 译文字号」小 / 中 / 大，默认中（12pt）。在「预览」里按适合宽度看，右边中文和左边原文差不多大。

## 六、已知的限制

- 双栏 PDF 只支持 PDF；扫描件没有文字层，右边写「读不出字」。
- 原 PDF 自带的批注和链接不会带到双栏 PDF 里。
- 旋转过的页面（/Rotate）没测过。
- 后台任务只认 PDF；Zotero 交来的如果是别的格式会跳过。
- Mac 程序和 Zotero 插件我这边没法真的跑，只在模拟环境里把页面这一侧的流程测通了（排队、存盘位置、交回 Zotero 的内容、菜单栏进度）；Rust 外壳和 Zotero 插件要小宝第一次实测。
